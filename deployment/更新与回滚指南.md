# XBot 更新与回滚指南

## 一、更新前先确认

在开发机项目目录执行：

```powershell
cd D:\比特x养号_2
git status --short
git log --oneline -3
```

本次帮助优化前已经创建本地恢复点：

```text
backup-before-help-optimization-20260605-150900
```

如果需要回到帮助优化前：

```powershell
git reset --hard backup-before-help-optimization-20260605-150900
```

## 二、提交并上传到 GitHub

```powershell
cd D:\比特x养号_2
git add automation deployment 账号评分提示词.txt
git commit -m "optimize discord help and update deployment rollback"
git push origin main
git push origin --tags
```

如果 `git push` 连不上 GitHub，先不要更新服务器；等本地能成功 push 后再执行服务器更新。

## 三、Ubuntu 服务器更新

登录服务器：

```bash
ssh root@你的服务器IP
cd /opt/xbot
```

推荐使用脚本更新：

```bash
chmod +x deployment/server_update.sh
BRANCH=main APP_DIR=/opt/xbot bash deployment/server_update.sh
```

脚本会自动：

- 记录当前 commit 到 `backups/last_commit_before_update_时间.txt`
- 创建服务器本地 tag：`server-backup-before-update-时间`
- 备份 `automation/data` 和配置文件
- `git pull origin main`
- 安装服务端依赖
- 重启 `xbot-controller`
- 重启 `xbot-discord`，没有 systemd 服务时自动用 `nohup` 启动

## 四、手动更新命令

如果不用脚本：

```bash
cd /opt/xbot
STAMP=$(date +%Y%m%d_%H%M%S)
CURRENT_COMMIT=$(git rev-parse HEAD)
mkdir -p backups
echo "$CURRENT_COMMIT" > "backups/last_commit_before_update_${STAMP}.txt"
git tag -f "server-backup-before-update-${STAMP}" "$CURRENT_COMMIT"
tar -czf "backups/controller_db_${STAMP}.tar.gz" automation/data discord_config.yaml scheduler_config.yaml model_config.yaml 2>/dev/null || true
git pull origin main
python3 -m pip install -r deployment/requirements-controller.txt
systemctl restart xbot-controller
systemctl restart xbot-discord || true
pkill -f "automation/discord_bot.py" || true
nohup python3 automation/discord_bot.py --config discord_config.yaml > discord_bot.log 2>&1 &
curl -fsS http://127.0.0.1:8766/health
tail -n 50 discord_bot.log
```

## 五、服务器回滚

如果更新后异常，先找更新前 commit：

```bash
cd /opt/xbot
ls -lt backups/last_commit_before_update_*.txt | head
cat backups/last_commit_before_update_最近时间.txt
```

回滚代码：

```bash
cd /opt/xbot
git reset --hard 上一步看到的commit
systemctl restart xbot-controller
systemctl restart xbot-discord || true
pkill -f "automation/discord_bot.py" || true
nohup python3 automation/discord_bot.py --config discord_config.yaml > discord_bot.log 2>&1 &
```

如果需要恢复数据库/配置备份：

```bash
cd /opt/xbot
tar -xzf backups/controller_db_对应时间.tar.gz
systemctl restart xbot-controller
```

## 六、客户端更新

服务端更新只影响中央控制器和 Discord Bot。涉及 Worker 的功能，例如模式二抢占正在执行任务，需要把新客户端包发给客户端电脑：

```text
release/xbot-client_最新时间.zip
```

客户端电脑先退出 `XBotSupervisor.exe` 和 `XBotWorker.exe`，再替换新包并重新运行 `launch_xbot.bat`。
